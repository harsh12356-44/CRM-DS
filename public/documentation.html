Product Blueprint

1. Executive Overview & Purpose

Why HRM Pilot was created, the operational challenges it solves, and its foundational design philosophy.

HRM Pilot (CRM-DS) is an enterprise Human Resource Management and Workforce Operations Platform built for digital agencies, multi-branch conglomerates, and modern hybrid organizations. It merges formal office biometric compliance, remote WFH time tracking, multi-tier leave approval workflows, employee feedback routing, and payroll calculation into one cohesive, lightning-fast application.

🏢 Multi-Tenant Corporate Isolation

Supports multiple independent corporate entities (Digital Suncity, Apex Global Tech, etc.) within a single deployment with distinct staff rosters, branch allocations, and branding.

🎯 Smart Name-Matching Biometrics

Eliminates biometric machine ID collisions. Uses Levenshtein distance on employee names, ensuring monthly biometric Excel uploads match staff with 100% precision.

⏱️ High-Integrity WFH Tracking

Enforces an "Entire Screen" policy, features structured Tea (15m) and Lunch (45m) breaks, background decoding resilience, randomized capture intervals, and 7-day retention.

💡

Permanent Dark Mode Architecture

Following comprehensive user feedback and operational guidelines, HRM Pilot enforces a sleek, unified Dark Theme across all roles (Super Admin, HR Admin, Manager, Employee). This eliminates glare during 8–9 hour work shifts, maximizes contrast for status badges, and saves battery life on mobile devices.

2. 5-Minute Quick Start

Get the development server or local test instance running in 4 easy steps.

  • 1

    Clone Repository & Install Dependencies

    Clone the official repository from GitHub and install all dependencies using Node.js 20+.

    bash
    git clone https://github.com/harsh12356-44/CRM-DS.git
cd CRM-DS
npm install
  • 2

    Configure Environment Variables

    Copy .env.example to .env and provide your Supabase PostgreSQL credentials.

    env
    DATABASE_URL="postgresql://postgres.xxx:password@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?pgbouncer=true"
DIRECT_URL="postgresql://postgres.xxx:password@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres"
  • 3

    Generate Prisma Client

    Generate type-safe Prisma database client bindings from the schema.

    bash
    npx prisma generate
  • 4

    Start Development Server

    Launch the Next.js development server at http://localhost:3000.

    bash
    npm run dev

⚡ Zero-Latency In-Memory Querying

All active employees, attendance registers, time sessions, and leave records are held in a validated in-memory store. Reads and mutations execute in < 15 milliseconds, completely insulating users from external cloud network latency.

🛡️ Non-Regressive State Protection

Through mergeTimeEntriesNonRegressive and mergeLeavesNonRegressive, cloud database reads can never revert an open or completed clock-out back into an active state, eliminating race conditions across devices.

User Guide

6. Employee Portal Operational Guide

Complete daily walkthrough for all staff members.

1. Logging In & Device Memory

Navigate to /login. Enter your work email (e.g. sonu.digitalsuncity@gmail.com) or your employee ID (SG012).

  • Save Password on This Device: Check the box to remember your account on your personal laptop or phone. The next time you open the app, you can sign in with 1 click!
  • Eye Icon: Toggle to unmask and verify your password.
  • Forget This Device: Immediately erases saved credentials from that browser.

2. Daily Attendance & WFH Time Tracking

  • A

    Clocking In (Start of Day)

    Click the green "Clock In" button on your dashboard. When prompted by your browser, you MUST select "Entire Screen" and click Share. Selecting single tabs or windows will be rejected by company policy.

  • B

    Chrome's "Hide" Notification Bar

    Chrome displays a bar at the bottom: "HRM is sharing your screen [Stop sharing] [Hide]". Click "Hide" to tuck it away. Tracking continues normally!

  • C

    Taking Breaks

    Click "Tea Break" (15m) or "Lunch Break" (45m). Your timer pauses and screenshots stop. When ready to resume, click "Resume Work"—no permission prompt is needed!

  • D

    Clocking Out (End of Day)

    Click the red "Clock Out" button. Your timer freezes instantly and your worked hours are saved.

3. Leave Applications & Quotas

Click "Apply Leave". Select Leave Type (Casual, Planned, Sick), Duration (Full Day, First Half, Second Half), dates, handover notes, and submit. You will immediately be redirected to your Leave History tab to track Manager and HR approvals.

8. HR Administrator Suite Guide

Complete guide to payroll, staff onboarding, attendance imports, and settings.

Staff Onboarding

Add new staff under /admin/employees. Assign Branch (Main vs SEO), shift duration (8h vs 9h), weekly offs, and initial password.

Biometric Excel Upload

Import monthly Excel punch sheets under /admin/attendance. The engine matches staff by name, eliminating ID collisions.

Live Board & Timesheets

Monitor live remote clocks under /admin/time-tracking, inspect screenshots in high-res lightbox, and export CSV timesheets.

1-Click Database Save & Backup (💾 Save Database)

Located in the top header navbar. Clicking this flushes all in-memory changes, creates an immutable JSON snapshot under data/backups/db_backup_<timestamp>.json, and presents a synced records count confirmation toast.

DevOps

10. Hostinger Production & CI/CD

Automated deployment pipeline via GitHub Actions and Phusion Passenger.

Automated Deployment Workflow (.github/workflows/deploy.yml)

Every push to main triggers automated zero-downtime deployment:

  1. SSH connects securely to Hostinger server (88.222.247.3:65002).
  2. Backs up live data/db.json to /tmp/hrm_live_db_backup.json before pulling code.
  3. Executes git reset --hard origin/main.
  4. Restores /tmp/hrm_live_db_backup.json to preserve live user passwords and punches.
  5. Runs npm install, npx prisma generate, and compiles production chunks.
  6. Purges LiteSpeed edge caches (X-LiteSpeed-Purge: *) and restarts Phusion Passenger.

11. Frequently Asked Questions

Answers to common operational and technical questions.

Why does my attendance schedule look like a vertical timeline on my mobile phone? ▼
Traditional 31-day attendance tables require over 1,300px of width, which forces awkward horizontal scrolling on phones. HRM Pilot transforms the schedule into a clean, vertical daily list on mobile devices so you can effortlessly scroll down the screen.
Can I click "Hide" on Chrome's bottom screen share notification bar? ▼
Yes! Clicking "Hide" is 100% safe. The browser keeps streaming frames in the background without any disruption to your session.
Why are Time Tracker hours separate from Biometric Attendance? ▼
Biometric attendance represents physical office scanner compliance used for official payroll. The Time Tracker measures active WFH sessions, tea/lunch breaks, and overtime. HR reviews both separately via the Timesheets tab.
